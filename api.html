Частично обновить черновик (статус или замена преподавателя/аудитории)

Поддерживает два типа операций:

  1. Изменение статуса черновика (например, публикация).
  2. Замена преподавателя и/или аудитории для одного или нескольких занятий.
Authorizations:
BearerAuth
Request Body schema: application/json
required
One of
status
required
string
Enum: "DRAFT" "PUBLISHED"

DRAFT — черновик (можно редактировать) PUBLISHED — опубликованное расписание (доступно всем)
